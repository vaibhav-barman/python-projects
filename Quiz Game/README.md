# 🐍 Computer Quiz Game

A simple, interactive command-line quiz game built with Python. Test your knowledge of basic computer hardware terminology and see how many questions you can answer correctly!

## 🎮 Features

- Four questions about computer hardware
- Case-insensitive answer checking
- Score tracking
- Final score and percentage calculation
- Option to exit before starting the quiz

## 🛠️ Requirements

- Python 3.x
- No external libraries required

## 🚀 How to Run

1. Make sure Python 3 is installed.
2. Clone the repository if you haven't already:

   ```bash
   git clone https://github.com/vaibhav-barman/python-projects.git
   ```

3. Open the repository folder and navigate to the Quiz Game directory:

   ```bash
   cd python-projects
   cd "Quiz Game"
   ```

4. Run the Python script. Replace `main.py` with the actual filename containing the quiz code:

   ```bash
   python3 main.py
   ```

## 📝 How to Play

1. Run the program.
2. Type `yes` when asked whether you want to play.
3. Answer each question by entering the full term.
4. View your final score out of 4 and your percentage.

Enter anything other than `yes` at the start to exit the game.

## ❓ Sample Questions

- What does CPU stand for?
- What does GPU stand for?
- What does RAM stand for?
- What does PSU stand for?
